# Context Kit Store Listing Draft

## Title

Context Kit

## Short Description

Save AI conversations as reusable context packages and bring the right project memory back into ChatGPT and Gemini.

## Detailed Description

Context Kit helps teams and solo builders preserve useful project context from AI conversations without copying everything into scattered notes.

Use Context Kit to:

- capture a full conversation from supported AI tools
- save selected text when you only want part of the thread
- review and clean up the package before saving
- flag and redact sensitive content before it is stored
- search saved packages by title, summary, tags, platform, and recency
- export packages as JSON for backup or sharing
- reinsert a polished version of the saved context back into the current tool

Context Kit is designed for active work, not passive scraping. It reads supported AI pages only when you explicitly ask it to capture or insert context.

The store build is local-first. Cloud sync and workspace collaboration remain available in development and self-hosted builds, but are intentionally disabled in the Chrome Web Store package until the production backend, auth flow, and public privacy endpoints are finalized.

## Category Suggestion

Productivity

## Single Purpose

Capture, organize, and reuse user-selected AI conversation context from supported AI tools.

## Suggested Privacy Disclosures

Collected data types to review in the dashboard:

- website content, only on supported AI sites and only when the user captures context
- user-provided content stored inside saved Context Packages

Not currently required for the store build:

- financial information
- health records as a product category
- personally identifying profile data from account sign-in
