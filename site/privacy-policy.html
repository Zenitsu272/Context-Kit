Context Kit Privacy Policy

Last updated: November 3, 2026

The maintained policy for version 0.2 is available in the project privacy policy.

Optional Gemini and attached files

Attached files are stored locally in IndexedDB. PDF/text extraction runs on-device. Enabling Gemini does not automatically send conversations: Enhance with Gemini sends draft and extracted text; Read with Gemini sends the selected original image, PDF or short video to Google without redaction. API terms, quota and billing apply. Credentials stay in the Edge profile and are excluded from backups.

Import file requests access only to the selected source origin and may use existing sign-in cookies. JSON backups include original files. Deleted or removed files can be cleaned up from Settings after 24 hours when no saved package or active draft refers to them.

What Context Kit stores

  • Context Packages created by the user
  • message excerpts, summaries, tags, notes, and review warnings inside each package
  • lightweight auth session state in development builds that enable cloud sync
  • workspace membership and version history when cloud sync is enabled

How data is used

  • to help users save, organize, search, and reuse project context across AI tools
  • to support workspace collaboration and package version history in cloud-enabled builds
  • to support security review features such as sensitive-content warnings and redaction prompts

How data is collected

Context Kit reads supported AI pages only when the user explicitly triggers a capture action such as saving the current conversation or capturing selected text.

Data sharing

  • personal packages remain private by default
  • workspace packages can be shared with workspace members based on role and visibility rules
  • the Edge build is local-first and does not enable production cloud sync by default

User controls

  • edit or delete packages
  • export packages as JSON
  • redact drafts before saving

Contact

Contact Context Kit support. Do not include keys or private files in public issues.
